# 📚 Система управления библиотекой

> Консольное Java-приложение на принципах объектно-ориентированного программирования  
> Курсовая работа по Java (OOP)

---

## 📌 Описание

**Library Management System** — это консольное приложение, которое позволяет:

- Добавлять, просматривать и удалять книги, журналы, электронные книги
- Регистрировать читателей
- Выдавать и принимать возврат книг
- Искать элементы по названию и автору
- Оценивать книги (рейтинг от 1 до 5)
- Просматривать статистику библиотеки

---

## 🏗️ Архитектура проекта

```
LibrarySystem/
└── src/main/java/library/
    ├── Main.java                     ← Точка входа
    ├── model/
    │   ├── LibraryItem.java          ← Абстрактный базовый класс
    │   ├── Book.java                 ← Книга (наследует LibraryItem)
    │   ├── EBook.java                ← Эл. книга (наследует Book)
    │   ├── Magazine.java             ← Журнал (наследует LibraryItem)
    │   ├── Reader.java               ← Читатель
    │   ├── Borrowable.java           ← Интерфейс выдачи
    │   └── Rateable.java             ← Интерфейс оценки
    ├── service/
    │   └── LibraryService.java       ← Бизнес-логика (Singleton)
    ├── exception/
    │   ├── ItemNotFoundException.java
    │   ├── ItemNotAvailableException.java
    │   └── ReaderNotFoundException.java
    └── ui/
        └── ConsoleMenu.java          ← Консольное меню
```

## ✅ Использованные концепции ООП

| Концепция | Где используется |
|---|---|
| **Классы и объекты** | `Book`, `Magazine`, `EBook`, `Reader`, `LibraryService` |
| **Инкапсуляция** | Все поля `private`, доступ через `getter/setter` |
| **Модификаторы доступа** | `public`, `private`, `protected` во всех классах |
| **`this`** | В конструкторах: `this.title = title` |
| **`static`** | `itemCounter`, `readerCounter`, `LibraryService.getInstance()` |
| **`super`** | `EBook` → `Book` → `LibraryItem`, вызов `super(...)` |
| **Наследование** | `LibraryItem` → `Book` → `EBook`; `LibraryItem` → `Magazine` |
| **Полиморфизм** | `@Override getType()`, `getFullInfo()`, `checkOut()` |
| **Абстрактный класс** | `abstract class LibraryItem` с методами `getType()`, `getFullInfo()` |
| **Интерфейсы** | `Borrowable` (выдача), `Rateable` (оценка) |
| **Исключения** | `try-catch-finally`, `throw`, `throws`, 3 кастомных исключения |

## 🚀 Как запустить

### Способ 1 — через скрипт (Linux/Mac)

```bash
cd LibrarySystem
chmod +x compile.sh run.sh
./compile.sh
./run.sh
```

### Способ 2 — вручную

```bash
# Компиляция
find src -name "*.java" > sources.txt
javac -d out @sources.txt

# Запуск
java -cp out library.Main
```

### Способ 3 — IntelliJ IDEA

1. Открыть папку `LibrarySystem` как проект
2. Найти `Main.java`
3. Нажать ▶️ Run
